## TradeSignal

Generated by AI — represents a trading opportunity.

```python
@dataclass
class TradeSignal:
    asset_type: AssetType
    symbol: str                    # e.g., "BTC/USDT", "XAUUSD"
    direction: TradeDirection      # BUY or SELL
    entry_price: float             # price to enter
    quantity: float                # amount to trade
    stop_loss: Optional[float]     # price to cut loss
    take_profit: Optional[float]  # price to take profit
    confidence: float = 0.0       # 0.0–1.0, threshold default 0.75
    reasoning: str = ""            # AI explanation
    timestamp: datetime            # generated at
```

**Example:**
```python
TradeSignal(
    asset_type=AssetType.CRYPTO,
    symbol="BTC/USDT",
    direction=TradeDirection.BUY,
    entry_price=62500.0,
    quantity=0.01,
    stop_loss=61250.0,    # -2%
    take_profit=65625.0,  # +5%
    confidence=0.82,
    reasoning="RSI oversold, golden cross forming on 4H"
)
```

## Trade

An executed trade — stored in SQLite.

```python
@dataclass
class Trade:
    id: Optional[int]             # DB primary key
    symbol: str
    asset_type: AssetType
    direction: TradeDirection
    entry_price: float
    exit_price: Optional[float]  # None until closed
    quantity: float
    stop_loss: Optional[float]
    take_profit: Optional[float]
    status: TradeStatus
    entry_time: Optional[datetime]
    exit_time: Optional[datetime]
    trade_number: int             # "ไม้ที่ X" for this symbol

    @property
    def pnl(self) -> Optional[float]:
        """P&L in quote currency"""
        if self.exit_price is None:
            return None
        if self.direction == BUY:
            return (exit_price - entry_price) * quantity
        else:  # SELL (short)
            return (entry_price - exit_price) * quantity

    @property
    def pnl_percent(self) -> Optional[float]:
        """P&L as percentage"""
        ...
```

**P&L Logic:**
- BUY: `(exit_price - entry_price) * quantity`
- SELL: `(entry_price - exit_price) * quantity`

**Example trade:**
```
Trade #1: BTC/USDT
BUY 0.01 @ 62,500
→ Close @ 65,625 (TP hit)
P&L = (65,625 - 62,500) * 0.01 = 31.25 USDT
```

## TradeResult

Aggregated statistics from SQLite queries.

```python
@dataclass
class TradeResult:
    total_trades: int = 0
    winning_trades: int = 0
    losing_trades: int = 0
    total_pnl: float = 0.0
    win_rate: float = 0.0        # percentage
    avg_win: float = 0.0
    avg_loss: float = 0.0

    def calculate_metrics(self):
        self.win_rate = winning / total * 100
        self.avg_win = total_pnl / winning if winning > 0 else 0
        self.avg_loss = abs(total_pnl) / losing if losing > 0 else 0
```

## SQLite Schema

```sql
CREATE TABLE trades (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    symbol TEXT NOT NULL,
    asset_type TEXT NOT NULL,        -- "crypto" or "gold"
    direction TEXT NOT NULL,         -- "buy" or "sell"
    entry_price REAL NOT NULL,
    exit_price REAL,                -- NULL until closed
    quantity REAL NOT NULL,
    stop_loss REAL,
    take_profit REAL,
    status TEXT NOT NULL,           -- "pending", "open", "closed", "cancelled"
    entry_time TEXT,                -- ISO format
    exit_time TEXT,
    trade_number INTEGER NOT NULL,  -- sequential per symbol
    created_at TEXT DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_trades_symbol ON trades(symbol);
CREATE INDEX idx_trades_status ON trades(status);
```
